# 位运算（针对二进制整数而言）的知识点

## 六种运算符

例子统一取 x = 13 = 1101₂，y = 5 = 0101₂

- &（按位与）：都是1才为1，如1101 & 0101 = 0101
- |（按位或）：有1则为1，如1101 | 0101 = 1101
- ^（按位异或）：一个是1，一个是0才为1，如1101 ^ 0101 = 1000
- ~（按位取反）：每位翻转；Python 里 ~x = -x - 1（先记住这公式，看后面学不学）
- <<（左移）：低位补 0，等价于 ×2，如13 << 1 = 26
- >>（右移）：高位补符号位，等价于 ÷2 向下取整，如13 >> 1 = 6，-3 >> 1 = -2

## 按位异或^的性质

- x ^ x = 0
- x ^ 0 = x
- 运算满足交换律和结合律

按位异或的用处：一堆数里只有一个出现一次，其余成对，全部异或完剩下的就是它。“成对抵消、孤者胜出”是异或的招牌套路。

## 补充

```python
x & 1          # 判断奇偶：1 是奇数，0 是偶数（比 x % 2 更底层的直觉）
x & (x - 1)    # 消掉最低位的那个 1（数 1 的个数、判 2 的幂都用它）
1 << k         # 造出第 k 位为 1 的数，当"位掩码"用
```
