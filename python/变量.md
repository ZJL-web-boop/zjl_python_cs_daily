# 变量的作用

计算机中的存储空间，用来保存数据。

## 注意（Python 的特别之处）

上面是 C 语言的"盒子"模型；Python 的变量更像是**名字贴在对象上**（名字 → 对象的引用），变量本身不存数据：

```python
a = [1, 2]
b = a       # b 不是 a 的拷贝，是同一个列表的另一个名字
b.append(3)
print(a)    # [1, 2, 3] ← a 也变了！
```

这就是 LC66 递归版里 `lis = digits` 没起到保护作用的原因（两个名字指同一个列表），而 `lis = digits[:]` 切片才是真拷贝——"盒子模型"在这里会直接翻车。
