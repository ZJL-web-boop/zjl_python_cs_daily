# Python 学习自检清单

> 用法：配合廖雪峰教程使用。每学完一个模块，对照清单逐条自检——能不看资料说出/写出，才算过关，打勾。  
> 学习节奏：每天 45–60 分钟系统阅读 + 刷题时应用。**每周日晚花 20 分钟过一遍清单，查漏补缺。**

## 阶段一：语言基础（对应廖雪峰：Python 基础）

- [×] 变量与赋值：知道 Python 变量是"名字 → 对象"的引用，不是盒子
- [ ] 基本类型：int（无大小限制）、float、str、bool、None
- [ ] 运算符：`/` vs `//` vs `%`；`and` / `or` / `not`（绝不是 `&` `|`）
- [ ] 字符串：拼接、格式化（f-string）、切片 `s[a:b:c]`、常用方法（`split` `join` `strip` `replace`）
- [ ] 条件与循环：`if/elif/else`、`for x in ...`、`while`、`break/continue`
- [×] `range()` 和 `enumerate()`：什么时候用哪个

## 阶段二：数据结构（核心，面试必考）

- [ ] list：增删改查、`append/insert/pop/remove`、切片、排序 `sort` vs `sorted`
- [ ] tuple：不可变意味着什么、什么时候用（返回多值、字典键）
- [ ] dict：增删查改、`get()` 的默认值、遍历 keys/values/items、**O(1) 查找的原因**
- [ ] set：去重、交并差集、`in` 判断为什么快
- [ ] **能说出四种结构分别适用什么场景**（这是"精"的标志，比如：为什么两数之和用 dict 不用 list）

## 阶段三：函数

- [ ] def 定义、参数（位置/关键字/默认值）
- [ ] 返回值：单值、多值（其实是 tuple）、None
- [ ] 作用域：局部变量 vs 全局变量，为什么不要乱用 global
- [ ] 列表推导式：`[x*x for x in lst if x > 0]`——能读能写
- [ ] lambda：一句话函数，`sorted(key=lambda x: x[1])` 这种用法要熟

## 阶段四：面向对象（够用即可，不深究）

- [ ] class 定义、`__init__`、`self` 是什么
- [ ] 实例属性 vs 类属性
- [ ] 继承基础：`class B(A)`、`super()`
- [ ] 能读懂 LeetCode 的 `class Solution:` 为什么这么写
- [ ] 魔术方法概念：`__len__`、`__str__` 知道存在即可

## 阶段五：工程必备（实习前必须会）

- [ ] 文件读写：`with open(...) as f` 的写法，为什么用 with
- [ ] 异常处理：`try/except/finally`，什么时候该抛什么时候该接
- [ ] 模块与包：`import`、`from x import y`、pip 装包
- [ ] 虚拟环境：知道 `.venv` 是干嘛的（你已经被它坑过一次了）
- [ ] 常用标准库过一眼：`collections`（deque/Counter）、`heapq`（刷题常用）、`math`、`itertools`

## 阶段六：进阶（刷题 100 题后再看，不急）

- [ ] 迭代器与生成器：`yield` 是什么
- [ ] 装饰器：能读懂别人的装饰器即可
- [ ] 类型注解：`def f(x: int) -> bool`（现代 Python 代码都这么写）
- [ ] 排序进阶：`sorted` 的 `key` 和 `reverse` 参数、自定义比较

---

## "学精"的三个标准（自测）

1. **能讲**：不看资料，把 list/dict/set 三者的区别和适用场景讲给同学听 3 分钟
2. **能选**：拿到新问题，第一反应是"该用哪种结构"，而不是"先写个循环再说"
3. **能纠错**：看到 `s /= 10` 或 `a & b`（想表达 and）能立刻发现不对——这个你已经达标了

## 红线（不要做的事）

- ❌ 不要抱着《流畅的 Python》《Python 源码剖析》这种书啃——那是工作 2 年后看的
- ❌ 不要追求"精通 Python"才去学下一阶段——你 4 个月的目标是 LLM 应用，Python 是工具不是目的，够用 + 在用中加深
- ❌ 不要跳过动手：每个知识点必须在 PyCharm 里敲过一遍才算学过
