# 四种数值类型

## int整型（任意大小的整数）

- 检验数据类型的函数type()

比如：

```python
num = 1
print(type(num)) # 输出：<class 'int'>
```

## float浮点型

- 由于浮点数误差，两个浮点数是不能直接进行相等的比较的，对此，可以调用math.isclose(a, b)来解决这一经典问题
```python
import math
print(0.1 + 0.2 == 0.3) # 输出的是False
print(math.isclose(0.1 + 0.2, 0.3)) # 输出的是True
```

## bool布尔型

- 在Python中，布尔值可以当作整型来对待，True当作1，False当作0；

```python
print(True+False) # 输出为1，不报错
```

## complex复数型

```python
print(2 + 3j) # 注意这里的虚数只能是j，不能是i
```
