# 格式化输出

## 方式一：%

- %s:字符串
- %d:整数

```python
name = "Li Hua"
age = 18
print("我的名字叫：%s" % name) # 注意这里与C语言不同之处在：name前面也要有%号
print("我的名字叫：%s，我今年%d岁了" % (name, age)) # 注意name和age的顺序不能搞反，中间用逗号隔开
```

- %4d: 前面的数字表示位数，如果不足的话前面会补空格，刚好或超出这位数则输出原数

```python
n = 123
print("%4d" % n)
print("%04d" % n) # 前面的空格变为0
print('%2d' % n)
```

- %f:浮点数，默认保留后六位小数，遵循四舍五入原则

```python
a = 1.234
print("%f" % a)
b = 1.2345677
print("%f" % b) # 输出1.234568
b = 1.2345673
print("%f" % b) # 输出1.234567
```

- %.4f:数字设置小数位数，遵循四舍五入原则
