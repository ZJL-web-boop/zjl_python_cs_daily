# 一、LeetCode 242.字符异位词

## 题目

两个字符串所包含的字符种类和数量完全相同，但是字符的顺序不同，这样的字符串我们称其为字符异位词。

现在我们要判断给定的字符串s和t是否为字符异位词，是返回True，否则返回False。

## 解法：哈希表+计数

思路：两个字符串互为字符异位词，相当于其所含的字符种类和数量是完全一致的，所以这个问题本质上又是字符种类+数量的问题。

因此，我们可以采用带值的哈希表（字典）来解决这一问题。

代码：

```python
class Solution(object):
    def isAnagram(self, s, t):
        if len(s) != len(t): # 如果两个字符串的长度不相等，那肯定不是字母异位词（提前收工）
            return False
        dic = {}
        for c in s: # 构建一个哈希表，记录字符串s中的字符(key)和其对应的数量(value)
            dic[c] = dic.get(c,0) + 1
        for c in t:
            if c not in dic: # 如果t中的某字符不在s，那这二者必定不是字母异位词
                return False
            dic[c] -= 1 # 库存减1
        for c in dic: # 如果是字母异位词的话，最后字典中各字符的数量应该均为0
            if dic[c] != 0:
                return False
        return True
```

时间复杂度与空间复杂度分析：此算法的空间复杂度为O(len(s))，最坏时间复杂度为O(2len(s)+len(t))（三个循环：建表、提货、终检各扫一遍）。

但是我们仔细想想，由于最后还有一个for循环去检验库存数量是否都为0了，遍历次数变多（注意：渐进复杂度量级没变，都是O(n)，变大的是常数因子），那我们能不能把这步给优化掉呢？

### 优化思路

由于我们已经进行了一个前置判断：如果两字符串的长度不相等的话，那他们肯定不是字符异位词。

所以我们在这判断语句之后再返回False的原因有：

- t中有的字符，s中却没有；
- t中的字符全在s中出现过，但数量上有出入：由于二者长度一致，但凡t里某个字符多提一次，就会在那一刻撞到库存0；而如果一次都没撞到，n 次提货恰好耗尽 n 个库存，必然全 0；

所以我们可以在第二个for循环里使用dic.get(c,0)直接把两种失败情况涵盖进去，从而省去最后一个for循环。

优化后的代码：

```python
class Solution(object):
    def isAnagram(self, s, t):
        if len(s) != len(t): # 如果两个字符串的长度不相等，那肯定不是字母异位词（提前收工）
            return False
        dic = {}
        for c in s: # 构建一个哈希表，记录字符串s中的字符(key)和其对应的数量(value)
            dic[c] = dic.get(c,0) + 1
        for c in t:
            if dic.get(c,0) == 0:
                """
                如果t中的某字符不在s中，那二者必不是字母异位词；
                如果t中的字符全在s中出现过，由于二者长度一致，但凡t里某个字符多提一次，就会在那一刻撞到库存0；
                而如果一次都没撞到，n 次提货恰好耗尽 n 个库存，必然全 0     
                """
                return False
            dic[c] -= 1 # 库存减1
        return True
```

- 时间复杂度：O(len(s)+len(t))
- 空间复杂度：O(len(s))

## 收获

通过缜密的逻辑分析后使用get()函数涵盖了前置判断语句后返回False的情形，把终检循环优化掉，遍历次数从3n降到2n——注意渐进复杂度不变（都是O(n)），省掉的是常数因子，这和217"提前收工版"降低平均耗时是两种不同性质的优化。

# 二、Python 学习（七）

## 字符串的常见操作

查找元素：

- find()：检测某个子字符串是否包含在该字符串中，若存在的话就返回这个子字符串开始位置的下标，否则返回-1；

**find(子字符串，开始位置下标，结束位置下标)**,注意开始和结束位置的下标可以省略，表示在整个字符串中查找。（**查找区间是包前不包后的**）

```python
name = 'Zhang Jiale'
print(name.find('ang')) # 输出a的下标：2
print(name.find('y')) # 查找失败，返回-1
print(name.find('ang', 2, 4)) # 由于查找区间是包前不包后的，所以'g'不在该区间内，查找失败输出：-1
print(name.find('ang', 2, 5)) # 输出：2
print(name.find('a', 3)) # 输出：8，结束位置没写意味着一直到最后
print(name.find('a', 2)) # 输出：2，输出第一次出现位置的下标
```

- index():检测某个子字符串是否包含在该字符串中，若存在的话就返回这个子字符串开始位置的下标，否则会报错；

**index(子字符串，开始位置下标，结束位置下标)**,注意开始和结束位置的下标可以省略，表示在整个字符串中查找。（**查找区间是包前不包后的**）

```python
name = '我命由我不由天' 
print(name.index('命')) # 输出：1
print(name.index('命', 2)) # 设置开始寻找的位置下标为2，由于后面没有'命'，所以会报错
```

- count():返回某个子字符串在整个字符串中出现的次数，没有就返回0；

**count(子字符串，开始位置下标，结束位置下标)**,注意开始和结束位置的下标可以省略，表示在整个字符串中查找。（**查找区间是包前不包后的**）

```python
name = 'bingbing'
print(name.count('b')) # 输出：2
print(name.count('b', 1)) # 输出：1
print(name.count('b', 1, 3)) # 输出：0
print(name.count('b', 1, 4)) # 输出：0，包前不包后原则
print(name.count('bing')) # 输出：2
```

判断

- startswith():判断某个字符串是否以某个子字符串开头，是的话则返回True,否则返回False;

**startswith(子字符串，开始位置下标，结束位置下标)**,如果设置开始位置和结束位置下标，则是针对指定区间的判断。(同样是包前不包后)

```python
name = 'bingbing'
print(name.startswith('bing')) # 输出：True
print(name.startswith('bing', 0, 3)) # 输出：False
print(name.startswith('bing', 0, 4)) # 输出：True
```

- endswith():判断某个字符串是否以某个子字符串结尾，是的话则返回True,否则返回False;

**endswith(子字符串，开始位置下标，结束位置下标)**,如果设置开始位置和结束位置下标，则是针对指定区间的判断。(同样是包前不包后)

- isupper()/islower():检测字符串中是否所有字母全为大写/全为小写，是则返回True,否则返回False；

```python
print('zhang'.isupper()) # 输出：False
print('zhang'.islower()) # 输出：True
print('ZHANG'.isupper()) # 输出：True
```

修改元素

- replace():替换

**replace(旧内容,新内容,替换次数)**，注意如果替换次数不写的话，默认全部替换掉。

```python
name = 'Zhang Jiale'
print(name.replace('le', 'yi')) # 输出：Zhang Jiayi
print(name) # 注意还是输出：Zhang Jiale，所以replace()应该是返回一个新的字符串，而不是在原有的字符串上进行修改
print(name.replace('a', 'i', 1)) # 输出：Zhing Jiale
print(name.replace('a', 'i', 2)) # 输出：Zhing Jiile
print(name.replace('a', 'i')) # 输出:Zhing Jiile
```

- split()：分割字符串，并以列表的形式返回；

**split(用什么来分割, 分割次数)**，注意如果不写次数的话，默认全部分割。

```python
name = 'Zhang Jiale'
print(name.split('a')) # 输出：['Zh', 'ng Ji', 'le']
print(name.split('a', 1)) # 输出：['Zh', 'ng Jiale']
print(name.split('ang')) # 输出：['Zh', ' Jiale']
```

- capitalize()：使字符串第一个字符大写，其余均会变为小写（包括原先大写的字母）

```python
name = 'hello World'
print(name.capitalize()) # 输出：Hello world
print(name) # 输出：hello World
```

- lower()和upper():大小写转换

```python
name = "Zhang Jiale"
print(name.lower()) # 输出：zhang jiale
print(name.upper()) # 输出：ZHANG JIALE
```
