# Day 6 - LeetCode 58. 最后一个单词的长度

## 题目

计算字符串中最后一个单词的长度，其中单词前后由若干空格字符隔开，比如

```
    s = "   fly me   to   the moon  "
```

最后一个单词是moon，长度为4。

## 解法一：从左往右遍历字符串，用left和right分别记录每个单词的左右边界

思路：
- 假设s[i]是一个单词的左边界，则i要满足的条件是：

```
    s[i] != ' ' and (i == 0 or s[i-1] == ' ')
```

- 假设s[i]是一个单词的右边界，则i要满足的条件是：

```
    s[i] != ' ' and (i == len(s)-1 or s[i+1] == ' ')
```

这样从左往右遍历字符串，每个单词的left和right会分别相互覆盖，这样我们最后自然就得到了最后一个单词的左右边界。

## 代码:

```python
class Solution(object):
    def lengthOfLastWord(self,s):
        total_length = len(s) # 记录整个字符串的长度
        left = 0 # left用于记录同一个单词最开头那个字母的索引下标
        right = 0 # right用于记录同一个单词最后那个字母的索引下标
        for i in range(total_length): # 由于单词会相互覆盖，因此得到的就是最后一个单词的开头和结尾字母的索引下标
            if i == 0 and s[i] != ' ': # 字符串开头就是一个单词的情况（前面没有空格）
                left = i
            elif i+1 < total_length and s[i] == ' ' and s[i+1] != ' ': # 其它单词开头要满足的条件
                left = i+1
            if i+1 == total_length and s[i] != ' ': # 字符串结尾就是一个单词的情况（后面没有空格）
                right = i
            elif i+1 < total_length and s[i+1] == ' ' and s[i] != ' ': #其他单词结尾要满足的条件
                right = i
        return right - left + 1 # 注意要加1的操作
```

```python
使代码更加的简洁

                left = i
            if s[i] != ' ' and (i == len(s)-1 or s[i+1] == ' '): # 单词末尾字母要满足自身不为空格，且后一个字符（若存在）要为空格

        return right - left + 1 # 注意要加1的操作
```

### 补充：

第一版把边界情况显式写成 4 个分支（啰嗦但直白）；观察后发现：
左边界和右边界本质各只有 1 条规则，用短路求值把边界判断并进条件，
就缩成了第二版的 2 行——这和 LC20 有效括号里 not stack or dic[c] != stack.pop() 是同一个技巧。

## 缺陷：

正向遍历需要记录每一个单词的边界再取最后单词的边界——状态多、代码绕；
而这题只关心最后一个单词，从右往左只需处理第一个遇到的单词，逻辑天然贴合题意。

## 解法二：显然这道题我们从右往左遍历更好，遍历的第一个单词的长度就是答案。

思路：这里由于是遍历的第一个单词，我们就可以不用求单词的左右边界了，直接计算长度即可：
- 首先我们遇到空格直接跳过，直到遇见第一个不是空格的字符，记录此位置；
- 然后我们继续遍历，在没有遇见空格时，每遇见一个字符length就加1；

最终返回length即可。

代码：

```python
"""本次改进不同于以往两个版本，前两个版本是从前往后遍历字符串，
但这道题要的是最后一个单词的长度，所以从后往前遍历可能会更好
"""

class Solution(object):
    def lengthOfLastWord(self, s):
        i = len(s)-1 # 从后面开始遍历
        while i >= 0 and s[i] == ' ': # 自动跳过空格
            i -= 1
        length = 0 # 记录最后一个单词的长度
        while i >= 0 and s[i] != ' ': #数到下一个空格或开头为止
            length += 1
            i -= 1
        return length

```

## 两个解法的时间复杂度均为O(n)，其中n为字符串的长度。

## 收获

本次的收获主要是：

先想清楚题目真正要什么（最后一个单词），再选遍历方向——正向 = 维护全局状态、记住最后；
反向 = 只关心目标。这是继"特例→规律"后第二条元方法论。
