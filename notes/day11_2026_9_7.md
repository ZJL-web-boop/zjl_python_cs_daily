# 一、LeetCode  136.只出现一次的数字

## 题目

给定一个非空的整数数组，数组里面只有一个数出现了一次，其他的数均出现了两次，现在要求找出那个只出现一次的数字。

## 解法一：使用按位异或

思路：由于题目说数组里面只有一个数出现了一次，其他的数均出现了两次，显然这是提示我们可以使用**按位异或**来解决这一问题。
我们把数组中所有的数进行异或操作，由于按位异或具有以下规律：

```
# 具有交换律和结合律
x ^ x = 0
x ^ 0 = x
```

我们最终得到的结果就是那个单一出现的数。

代码：

```python
"""
由于题目说非空数组中除了一个数字只出现了一次，其余数字都出现了两次，
显然这是想提示我们用按位异或来解决这一问题。

时间复杂度为O(n)（n为列表长度），空间复杂度为O(1)
"""

class Solution(object):
    def singleNumber(self, nums):
        xor = 0 # 由于 0 ^ x = x ，所以这里的0对后续的异或操作没啥影响
        for i in nums:
            xor ^= i
        return xor
```

- 时间复杂度：O(n)（n为列表长度）
- 空间复杂度：O(1)

## 解法二：利用数学方法

思路：我们可以先把列表强制转换为集合（实现去重的操作）， 然后分别计算列表中元素总和sum1以及集合中的元素总和sum2，
二者相减从而得到出现两次的数字的总和sum3，
再用集合中元素的总和sum2减去sum3，得到的便是那个只出现一次的数字。

代码：

```python
"""
这道题也能用数学方法解决：我们可以先把列表强制转换为集合（实现去重的操作），
然后分别计算列表中元素总和sum1以及集合中的元素总和sum2，二者相减从而得到出现两次的数字的总和sum3，
再用集合中元素的总和sum2减去sum3，得到的便是那个只出现一次的数字。

时间复杂度为O(n)（n为列表长度），空间复杂度为O(n)
"""

class Solution(object):
    def singleNumber(self, nums):
        nums_set = set(nums) # 把列表强制转换为集合（实现去重的操作），注意这里增加了空间复杂度
        sum1 = sum(nums) # 计算列表中元素总和sum1
        sum2 = sum(nums_set) # 计算集合中的元素总和sum2
        sum3 = sum1 - sum2 # 出现两次的数字的总和sum3
        return sum2 - sum3 # 得到那个只出现一次的数字
```

- 时间复杂度：O(n)
- 空间复杂度：由于引入了一个集合，空间复杂度增加为O(n)

### 补充

由于集合是只有key值的哈希表，所以集合内是不存在重复元素的。

## 收获

- 建立了看到“只有一个数字出现了一次，其余的数字都出现了两次”等表述想到是否可用按位异或解决这一问题的条件反射
- 注意如果引进了其他的像集合、字典之类的结构，可能会增加空间复杂度，要注意分析这一点

# 二、LeetCode 217.存在重复数字

## 题目

现在给我们一个整数数组，如果这里面有重复的数字则返回True，否则返回False。

## 解法一：通过比较去重前后数字的个数是否发生改变来判断

思路：我们通过强制类型转换把列表转换为集合，然后通过比较列表和集合的长度判断是否有重复的元素：

- 如果不相等，则有重复元素，返回True
- 如果相等，则无重复元素，返回False

代码：

```python
"""
由于题目说只要有一个数在列表中出现了两次及以上，就返回True,否则返回False。
其实这是一道典型的消去重复数字的问题,如果去重之后数字的个数与去重之前相等，则意味着没有重复的数字。
所以我们这道题采用求长度方法去解决。

时间复杂度为O(n)（n为列表长度），空间复杂度为O(n)
"""


class Solution(object):
    def containsDuplicate(self, nums):
        nums_set = set(nums) # 把列表强制转换为集合（实现去重的操作），注意这里增加了空间复杂度
        return len(nums) != len(nums_set) # 只要有一个数在列表中出现了两次及以上，意味着这二个长度就不相等，返回True,否则返回False。
```

- 时间复杂度：O(n)（n为列表长度）
- 空间复杂度：O(n)

缺点：就算数组一开头就有重复元素，此方法在强制类型转换为集合时还是会把列表元素全部遍历完，这显然对于此种特殊情形不是最佳的方法，
那么我们能不能做到一旦发现有重复，就立刻返回True，不去遍历后面的元素了？（解法二）

## 解法二：发现一对重复，立刻返回，剩下的数不用看

思路：在遍历的过程中如果已经发现有重复数字了，我们可以直接返回True，这样我们发现一对重复，立刻返回，剩下的数不用看，
平均效率更高。

代码：

```python
"""
第二版是在第一版的基础上加以优化的，优化点在于：第一版是直接通过把列表强制转换为集合来去重的，这是需要遍历列表中的所有元素的，
但是我们如果在遍历的过程中就已经发现有重复数字了，我们可以直接返回True，这样我们发现一对重复，立刻返回，剩下的数不用看，
平均效率更高。

时间复杂度与空间复杂度：
最好情况（重复就在开头）：均为O(1) -- 这是第一版做不到的地方
最坏情况（重复在最后面）：均为O(n)，与第一版一样
"""

class Solution(object):
    def containsDuplicate(self, nums):
        nums_set = set() # 定义一个空集合
        for i in nums:
            if i in nums_set: # 发现一对重复，立刻返回True，剩下的不用看；另外这是哈希集合，查询操作复杂度为O(1)
                return True
            nums_set.add(i)
        return False

```

时间与空间复杂度分析:
- 最好情况（重复就在开头）：均为O(1) -- 这是第一版做不到的地方
- 最坏情况（重复在最后面）：均为O(n)，与第一版一样
- 所以平均来讲，第二种解法优于第一种

## 收获

- 在想出一个解法后要考虑一下有没有更好、更快的解法
- 注意定义一个空集合的正确方式是：

```python
nums_set1 = {} # 注意这不是定义了一个空集合，而是定义了一个空字典
nums_set2 = set() # 这才是定义一个空集合的正确方式
```

### 补充：先查后加 vs 先加后查

解法二代码里 `if i in nums_set` 必须写在 `nums_set.add(i)` 之前，顺序反了程序就废了：

```python
nums_set = set()
for i in nums:
    nums_set.add(i)          # 先加后查（错误写法）
    if i in nums_set:        # 第一个元素入册后，立刻就会查到"自己"
        return True          # → 第一个元素就触发，永远返回 True
    # 这个写法程序在第一个元素就结束了，根本走不到这里
```

对比正确写法（先查后加）：每个元素只和"历史"（已入册的）比较，查到重复才返回。

本质：**"重复"的定义是与"之前的元素"相同**，所以查必须发生在入册之前——查的是过去，加的是现在，顺序反了就变成"自己和自己重复"。

## 三目运算（不常用）

基本结构：为真结果 if 判断条件 else 为假结果

实例代码：

```python
a = 1
b = 2
print("a小于等于b") if a <= b else print("a大于b")
# 当a <= b时打印a小于等于b，否则打印a大于b
```
