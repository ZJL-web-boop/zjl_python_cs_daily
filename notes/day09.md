# 一、LeetCode 268. 丢失的数字

## 题目：

给定一个包含 [0, n] 中 n 个数的数组 nums ，找出 [0, n] 这个范围内没有出现在数组中的那个数。

## 解法一：暴力遍历

思路：我们直接对[0,n]中的数进行遍历，然后检验遍历的哪个数不在数组nums中。

代码：

```python
"""
第一版：其实如果不在乎效率的话，解决这问题很容易
我们可以直接暴力遍历[0,n]里的数，看看哪个数不在数组里（时间复杂度为O(n²)）（n为数组长度）
空间复杂度为O(1)
"""

class Solution(object):
    def missingNumber(self,nums):
        length = len(nums) # 记录整数数组长度
        ans = 0 # 用来存放最后的答案
        for i in range(length+1): # 遍历[0,length]中的数，看看哪个数不在nums里
            if i not in nums: # 对nums从左到右进行遍历寻找是否有等于i的数，结果是没找到，单单这一层的复杂度为O(n)
                ans = i
                break
        return ans
```

- 时间复杂度：因为for循环里还有一个对列表进行的in操作（它会依次遍历列表中的元素，从而判断哪个数不在数组中），所以时间复杂度为O(n²)（n为数组长度）;
- 空间复杂度：O(1)

缺点：显然，这种暴力算法的时间耗费较多，当数据量很大时不是最佳解法。

## 解法二：哈希集合实现复杂度为O(1)的查询操作

思路：解法二是在解法一的基础上进行优化，解法一的时间复杂度之所以为O(n²)，是因为在循环里面又有一个对列表的in操作。

我们如果能把循环里的这个查询操作的复杂度变为O(1)的话，整个算法的时间复杂度就变为了O(n)，效率大大提升，所以我们考虑使用哈希查询。

这里我们先普及一点：在Python中**字典**和**集合**都是哈希表，不过**集合中只有键key，没有值value**,这也恰恰印证了**集合中的元素不能重复**的特点。

代码：

```python
"""
第二版是在第一版的基础上进行优化，第一版的时间复杂度之所以为O(n²),是因为在循环里面又有一个in操作符：
如果针对列表进行查询的话，是要逐个遍历的，时间复杂度为O(n)。
那么我们能否使这个查询操作复杂度变为O(1)呢？ 使用哈希集合（set）（set不同于字典，它里面只有key，没有value）,查询时间复杂度为O(1)

但是由于引进了集合，空间复杂度为O(n)
"""

class Solution(object):
    def missingNumber(self, nums):
        nums_set = set(nums)  # 将列表转换为集合
        ans = 0 # 用来存放最后的答案
        for i in range(len(nums)+1): # 遍历[0,length]中的数，看看哪个数不在nums里
            if i not in nums_set: # 此步的时间复杂度为O(1)
                ans = i
                break
        return ans
```

- 时间复杂度：O(n)
- 空间复杂度：引入哈希集合优化了时间复杂度，但相应地牺牲了空间复杂度，由于集合要占据一定的空间，空间复杂度变为O(n)

既然解法二又牺牲了空间复杂度，那么有没有解法既能保证线性的时间复杂度，又能维持O(1)的空间复杂度呢？（下面两种解法）

## 解法三：数学方法

思路：既然只少了[0,n]区间内的一个数，那么我们就能够用这一区间的数的总和-列表中元素总和得到缺失的元素。

代码：

```python
"""
第三版使用了数学方法解决这一问题：既然只少了[0,n]区间内的一个数，
那么我们就能够用这一区间的数的总和-列表中元素总和得到缺失的元素
算法的时间复杂度为O(n)，空间复杂度为O(1)
"""

class Solution(object):
    def missingNumber(self, nums):
        return sum(range(len(nums)+1)) - sum(nums)
```

- 时间复杂度：O(n)
- 空间复杂度：O(1)

缺点：这种算法要求区间里的数的和，由于Python中整数是无限精度的，因此不需要考虑和太大导致溢出的问题；

但是在其他的语言中（如C语言、Java等），是需要考虑这一问题的。

## 解法四：利用位运算中的按位异或 ^ 操作

思路：数组 nums 中有 n 个数，在这 n 个数的后面添加从 0 到 n 的每个整数，则添加了 n+1 个整数，共有 2n+1 个整数。

在 2n+1 个整数中，丢失的数字只在后面 n+1 个整数中出现一次，其余的数字在前面 n 个整数中（即数组中）和后面 n+1 个整数中各出现一次，

即其余的数字都出现了两次。

根据出现的次数的奇偶性，可以使用按位异或运算得到丢失的数字。按位异或运算 ⊕ 满足交换律和结合律，且对任意整数 x 都满足 x⊕x=0 和 x⊕0=x。

由于上述 2n+1 个整数中，丢失的数字出现了一次，其余的数字都出现了两次，因此对上述 2n+1 个整数进行按位异或运算，结果即为丢失的数字。

代码：

```python
"""
第四版我们使用位运算中的按位异或来解决这一问题：
数组 nums 中有 n 个数，在这 n 个数的后面添加从 0 到 n 的每个整数，则添加了 n+1 个整数，共有 2n+1 个整数。
在 2n+1 个整数中，丢失的数字只在后面 n+1 个整数中出现一次，其余的数字在前面 n 个整数中（即数组中）和后面 n+1 个整数中各出现一次，
即其余的数字都出现了两次。
根据出现的次数的奇偶性，可以使用按位异或运算得到丢失的数字。按位异或运算 ⊕ 满足交换律和结合律，且对任意整数 x 都满足 x⊕x=0 和 x⊕0=x。
由于上述 2n+1 个整数中，丢失的数字出现了一次，其余的数字都出现了两次，因此对上述 2n+1 个整数进行按位异或运算，结果即为丢失的数字。

时间复杂度为O(n),空间复杂度为O(1)
"""

class Solution(object):
    def missingNumber(self, nums):
        xor = 0
        for i,num in enumerate(nums): # 同时取出索引和对应的元素：i为索引，num为元素
            xor ^= num ^ i
        return xor ^ len(nums)

```

- 时间复杂度：O(n)
- 空间复杂度：O(1)

优点：既能保证线性的时间复杂度，又能维持O(1)的空间复杂度，同时又没有数字溢出的问题。

## 收获

- 这道题采用了四种思路解答，后一种思路都是在前一种思路的基础上优化的，体会了不同算法在时间复杂度和空间复杂度上的优化；
- 学会使用哈希集合实现复杂度为O(1)的查询操作；
- 学会了使用位运算中的按位异或解决相关问题，一堆数里只有一个出现一次，其余成对，全部异或完剩下的就是它。“成对抵消、孤者胜出”是异或的典型特点。
