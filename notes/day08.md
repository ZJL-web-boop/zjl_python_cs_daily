# Day 8: Python学习（一）

## 编译型语言与解释型语言的区别

- 编译型语言（如C语言）是整个编译为机器码再运行，而解释型语言（如Python）是边编译边运行；
- 一般来说，编译型语言运行速度更快；

## 注释

- 多行注释既可以用双引号，也能用单引号；
- 快捷键：Ctrl+/创建多行单行注释，再点一下则撤销多行单行注释。

## Bug 与 Debug

### Bug

- IndentationError: unexpected indent（缩进） 缩进错误
- SyntaxError 语法错误

### Debug

- 设置断点，程序运行到设置断点语句之前（不含设置断点的语句)就停止运行

## print 输出函数的几个参数

- *value:值，*表示一次可以输出多个值，值与值之间需要用','分隔
- sep:用来间隔多个值的符号，一般默认sep = ' ',sep为字符串类型变量
- end:用来设定用什么来结尾，一般默认end = '\n',end为字符串类型变量

示例代码：
```python
print('哈哈哈','嘿嘿嘿','嘻嘻嘻')
print('哈哈哈','嘿嘿嘿','嘻嘻嘻',sep = ',')
print('哈哈哈', end = ' ')
print('嘿嘿嘿', end = '1')
print('嘻嘻嘻')
```
