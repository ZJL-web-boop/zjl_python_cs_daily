## 编译型语言与解释型语言的区别

- 编译型语言（如C语言）是整个编译为机器码再运行，而解释型语言（如Python）是边编译边运行；
- 一般来说，编译型语言运行速度更快；
- 补充：CPython 实际是先把整个源码编译成字节码（.pyc），再由解释器逐条执行字节码——严格说是"先编译成字节码，边解释边运行"，"边编译边运行"是简化说法，概念辨析时知道这层就行

## 注释

- 多行注释既可以用双引号，也能用单引号；
- 注意：三引号"注释"本质是字符串字面量，不是真注释——Python 的真注释只有 #。三引号块没被赋值时解释器会直接忽略它，所以能当注释用，但它的正式身份是 docstring（以后学到函数会再遇到）；
- 快捷键：Ctrl+/ 添加行注释（#），选中多行再按可批量注释/取消。

## print 输出函数的几个参数

- *value:值，*表示一次可以输出多个值，值与值之间需要用','分隔
- sep:用来间隔多个值的符号，一般默认sep = ' ',sep为字符串类型变量
- end:用来设定用什么来结尾，一般默认end = '\n',end为字符串类型变量

示例代码：
```python
print('哈哈哈','嘿嘿嘿','嘻嘻嘻')
print('哈哈哈','嘿嘿嘿','嘻嘻嘻',sep = ',')
print('哈哈哈', end = ' ')
print('嘿嘿嘿', end = '1')
print('嘻嘻嘻')
```

运行结果（建议自己跑一遍对照）：
```
哈哈哈 嘿嘿嘿 嘻嘻嘻
哈哈哈,嘿嘿嘿,嘻嘻嘻
哈哈哈 嘿嘿嘿1嘻嘻嘻
```

第一行验证默认 sep=' '；第二行验证 sep 改成逗号；第三行验证 end 改掉后不再换行——三行 print 在物理上连成了同一行，'1' 是第二个 print 的 end，正好证明 end 是"结尾符"而不是分隔符。
