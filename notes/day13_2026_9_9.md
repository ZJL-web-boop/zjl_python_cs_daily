# 一、LeetCode 290. 单词规律

## 题目

给定一种规律 pattern 和一个字符串 s ，判断 s 是否遵循相同的规律。

这里的**遵循**指完全匹配，例如， pattern 里的每个字母和字符串 s 中的每个非空单词之间存在着双向连接的对应规律。具体来说：

- pattern 中的**每个字母都恰好映射到 s 中的一个唯一单词**
- s 中的**每个唯一单词都恰好映射到 pattern 中的一个字母**
- **没有两个字母映射到同一个单词，也没有两个单词映射到同一个字母**
- s 不包含任何前导或尾随对空格
- s 中每个单词都被**单个空格**分隔

这道题和LeetCode 205.同构字符串的解法一致。

## 解法一：利用哈希表记录映射关系，进行双向映射检验

思路：总体上的思路和“LeetCode 205.同构字符串”一致，这里不再赘述，详情可参考笔记"day12_2026_9_8.md"。

这里我们主要讲下特别要处理的地方：由于是 pattern 里的字母和 s 中的**单词**进行匹配,那么首先我们要想办法怎样快速用
索引去访问这些单词，这对于字符串比较难操作，但**对字符串数组容易**，因此我们要用**s.split()函数**把字符串 s 转换为字符串数组。

代码：

```python
class Solution(object):
    def wordPattern(self, pattern, s):
        s_list = s.split() # 由于s中是一个个由单空格符分隔的单词，为了更好的直接用索引访问单词，这里我们把s转换为列表
        if len(s_list) != len(pattern): # 如果长度不相等的话，那一对一的映射关系必然不成立（“提前收工”），注意len()是O(1)的操作
            return False
        dic1 = {}
        for i, m in enumerate(pattern):
            if m not in dic1:
                dic1[m] = s_list[i]
            else:
                if dic1[m] != s_list[i]:
                    return False
        dic2 = {}
        for i, m in  enumerate(s_list):
            if m not in dic2:
                dic2[m] = pattern[i]
            else:
                if dic2[m] != pattern[i]:
                    return False
        return True
```

- 时间复杂度：O(N+M)(N和M分别是pattern和s的长度)
- 空间复杂度：O(N+M)

### 注意点

这里的提前收工语句是不能省略的，否则可能**出现IndexError**。比如当pattern = 'abc',s = 'dog cat',在进行第一个循环时i会越界。

## 解法二：利用zip()函数和集合

思路：这里的思路也不再赘述了，详情可参考笔记"day12_2026_9_8.md"。

代码：

```python
"""
第二版使用zip()函数和集合解决这一问题
"""

class Solution(object):
    def wordPattern(self, pattern, s):
        s_list = s.split() # 由于s中是一个个由单空格符分隔的单词，为了更好的直接用索引访问单词，这里我们把s转换为列表
        if len(s_list) != len(pattern):
            # 如果长度不相等的话，那一对一的映射关系必然不成立（“提前收工”）
            # 注意由于zip函数是按最短的截断“拉链”的，所以这判断就不能省了，因为可能出现像'ab'，'dog cat cat'的情况
            return False
        return len(set(zip(pattern, s_list))) == len(set(pattern)) == len(set(s_list))
```

- 时间复杂度：O(N+M)
- 空间复杂度：O(N+M)

### 注意点

这里的提前收工语句也不能省略，但原因不同：这里是由于zip()函数是按照最短的截断拉链的（且不报错），
所以**可能会出现像'ab'，'dog cat cat'却返回True的情况**。

# 二、LeetCode 350. 两个数组的交集

## 题目

给你两个整数数组 nums1 和 nums2 ，请你以数组形式返回两数组的交集。
返回结果中每个元素出现的次数，应与元素在两个数组中都出现的次数一致（如果出现次数不一致，则考虑取较小值）。
可以不考虑输出结果的顺序。

## 解法：哈希表+计数

思路：其实这道题本质上就是：我们既要判断一个元素是否是两数组共有的，还要比较数量的问题。所以这道题应该得用带值的哈希表。

我们随便选取其中一个数组，构建为key为整数元素，value为相应的数量的字典，然后遍历另一个数组，如果遍历到的某元素
也在字典中，即为两数组共有的，然后再看字典中这种元素还剩几个，如果还有的话，就把这个元素增加到新的列表中，并且对应的value值要减1，
否则跳过这元素。

代码：

```python
class Solution(object):
    def intersect(self, nums1, nums2):
        nums3 = [] # 用来存放交集元素
        dic = {} # 构架一个哈希表来记录其中一个数组中的元素和其对应的数量，注意元素为key，对应的数量value
        for i in nums1: # 构建记录nums1中的元素和其对应的数量哈希表
            if i not in dic:
                dic[i] = 1
            else:
                dic[i] += 1
        for i in nums2:
            if i in dic: # 如果i在表中，说明是交集元素
                if dic.get(i,0) > 0: # get函数会返回i对应的value值
                    nums3.append(i) # 元素进入列表，此操作的时间复杂度为O(1)
                    dic[i] -= 1 # 库存减1
        return nums3
```

- 时间复杂度：O(N+M)（其中N、M分别是nums1、nums2的长度）
- 空间复杂度：O(N)（N为nums1的长度）

### 注意点

注意要先看字典中那个元素还剩下多少，如果还有就把它增加到新列表中，并value减1，没有就跳过，这个顺序不能搞反了。

## 收获

- 又一次理解了"先查后加/减"的顺序——217 是先查后**加**，这里是先查后**减**（先看还剩几个，够才收走再减），同一家族的两种形态；
- 巩固了dic.get函数的使用；

## 待复习

## 关于使用len()函数的时间复杂度问题

在Python中这是O(1)的操作，因为在实现列表、集合、字符串等结构时会顺手维护一个"长度计数器"变量，len()函数只需要返回这个变量的值就行。

## 字符串的常见操作

1.+:字符串拼接

```python
print('10'+'10') # 会输出1010
```

2.*：重复输出

```python
print("一切都是最好的安排"*3) # 输出：一切都是最好的安排一切都是最好的安排一切都是最好的安排（注意相邻之间没有空格和换行）
```

3.查找元素：

- find()：检测某个子字符串是否包含在该字符串中，若存在的话就返回这个子字符串开始位置的下标，否则返回-1；

**find(子字符串，开始位置下标，结束位置下标)**,注意开始和结束位置的下标可以省略，表示在整个字符串中查找。（**查找区间是包前不包后的**）

```python
name = 'Zhang Jiale'
print(name.find('ang')) # 输出a的下标：2
print(name.find('y')) # 查找失败，返回-1
print(name.find('ang', 2, 4)) # 由于查找区间是包前不包后的，所以'g'不在该区间内，查找失败输出：-1
print(name.find('ang', 2, 5)) # 输出：2
print(name.find('a', 3)) # 输出：8，结束位置没写意味着一直到最后
print(name.find('a', 2)) # 输出：2，输出第一次出现位置的下标
```
