# 一、LeetCode 9. 回文数

## 题目

回文数是正序和逆序读都一样的整数，如 121 是回文数，-121 不是。给定整数 x，判断它是否为回文数。

## 解法一：数学反转（取余拼接）

思路：负数直接排除，个位数必为回文，可优先判断。

当 x > 9 时，用纯算术把 x 反转：
- `x % 10` 取出个位
- `x // 10` 去掉个位
- 每取一位，拼到新数的末尾：`s1 = s1 * 10 + x % 10`（乘十进位把之前的数字推向高位）

最后比较 s1 和原数是否相等。

- 时间复杂度：O(log x)（x 的位数）
- 空间复杂度：O(1)

```python
class Solution(object):
    def isPalindrome(self, s):
        if s < 0:
            return False
        elif 0 <= s < 10:
            return True
        else:
            s1 = 0
            s2 = s
            while s > 0:
                s1 = s1 * 10 + s % 10
                s //= 10
            return s1 == s2
```

### 踩坑记录（重要）

1. **`/` 是浮点除，`//` 才是整数除**。写成 `s /= 10` 后 s 变成 12.1 这样的浮点数，永远除不到精确的 0，循环出错甚至死循环。C 里对 int 的 `/` 就是整除，Python 不是。
2. **逻辑与是 `and`，不是 `&`**。`&` 是位运算，且优先级比比较运算符高，`s >= 0 & s < 10` 实际解析成 `s >= (0 & s) < 10`，碰巧蒙对但纯属运气。

## 解法二：转字符串 + 切片反转

思路：整数转字符串，与它的反向切片比较。

- 时间复杂度：O(n)，n 为位数
- 空间复杂度：O(n)

```python
class Solution(object):
    def isPalindrome(self, s):
        s1 = str(s)
        return s1 == s1[::-1]  # [::-1] 是切片反转，得到的是字符串
```

### 概念辨析（面试相关）

- 解法一**不是栈**，是纯算术反转：没有辅助容器、没有 push/pop，正确性来自 `*10` 进位，与后进先出无关
- 判断一道题是不是"栈的题"：把栈抽掉，算法还成立吗？成立（或根本没有栈）就不是
- 若把数字转成列表从尾部 pop 再拼接，那才是真正的栈解法（但更绕，不如数学法）

# 二、LeetCode 20. 有效的括号

## 题目

给定只含 `()[]{}` 的字符串 s，判断是否有效：左括号必须以正确顺序、用相同类型右括号闭合。

## 解法：栈 + 字典配对表

思路：

1. 定义匹配关系 `dic = {"(": ")", "[": "]", "{": "}"}`
2. 遍历字符串：
   - 左括号 → 入栈（append）
   - 右括号 → 弹出栈顶（pop）：
     - 栈空却遇到右括号 → False（如 `"]"`）
     - 弹出的左括号与当前右括号不配对 → False（如 `"(]"`）
3. 遍历结束：栈空 → True；栈非空 → False（如 `"(("`）

三种失败情况：**栈空来右括号 / 栈顶不配 / 遍历完栈非空**。

```python
class Solution(object):
    def isValid(self, s):
        dic = {"(": ")", "[": "]", "{": "}"}
        l = []
        for c in s:
            if c == '(' or c == '[' or c == '{':
                l.append(c)
            else:
                if not l:          # 失败情况1：栈空来右括号
                    return False
                last = l.pop()
                if c != dic[last]:  # 失败情况2：栈顶不配
                    return False
        return len(l) == 0         # 失败情况3：栈非空
```

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 收获

- 栈的本质：**最后出现的左括号，最先被匹配**（后进先出），这是括号类问题选栈的原因
- Python 没有专门的 Stack 类，用 list 代替：`append` 入栈、`pop()` 出栈、`l[-1]` 看栈顶，尾部操作都是 O(1)
- `if c == '(' or c == '[' or c == '{'` 可简化为 `c in "([{"`
- 奇数长度字符串可直接 `return False`（小优化）
