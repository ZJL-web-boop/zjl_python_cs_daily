# 一、LeetCode 205. 同构字符串

## 题目

如果字符串s中的每个字符通过一一映射关系最终得到字符串t，我们称这两个字符串为同构字符串。这种映射关系需要满足以下几点：

- 不允许一种字符能映射到多种字符；
- 不允许多种字符能映射到同一字符；
- 允许字符自己映射到自己；

现在给我们两个字符串，是同构字符串则返回True,否则返回False。

## 解法：用哈希表+匹配的思路

思路：我们可以通过构建一个哈希表（字典）来记录 s→t 的映射关系，遇到新的映射关系则增加，遇到已有的映射关系则检验其映射是否正确；

但需要注意的是，单单满足 s→t 的映射关系并不能判断两字符串同构，因为可能会出现**多对一**的情况:

比如，s="bcda"，t="haea"，字符'c'和'a'均映射为'a'，这是不满足题意的，但是这满足 s→t 的映射关系；

我们可以看出用**遇到新的映射关系则增加，遇到已有的映射关系则检验其映射是否正确**这一判定方法，在 s→t 的映射中并不能检测到上述例子的问题，

但是在**t→s 的映射中便能体现出问题所在**，字符'a'可以映射到'c'和'a'，映射关系不正确，返回False。

所以，正是由于这一一映射关系，我们既要检验 s→t 的映射关系，也要检验 t→s 的映射关系。

代码：

```python
"""
题目说如果 s 中的字符可以按某种映射关系替换得到 t ，那么这两个字符串是同构的，
同时要注意每个出现的字符都应当映射到一个字符（允许映射到自己），同时不改变字符的顺序，
不同字符不能映射到同一个字符上，相同字符只能映射到同一个字符上，字符可以映射到自己本身（只能是一对一的关系）。
正是因为只能是一对一的映射关系，所以只考虑由 s → t的做法是有问题的：
比如 s="badc"，t="baea",这个输入是能满足s → t的映射的，但是显然字符a和c都映射为a，不满足题意。
所以题目的要求应该为s → t和t → s的映射都要满足，上面例子显然不满足后者。

时间复杂度：O(n)（n为字符串的长度）
空间复杂度：O(n)
"""
# 题目已经声明两字符串的长度是一样的，均大于等于1

class Solution(object):
    def isIsomorphic(self, s, t):
        match1 = {} # 构建一个带值的哈希表来记录映射关系
        for i,m in enumerate(s): # 同时取出索引i和对应字符m
            if m not in match1: # 如果哈希表里面原来没有这个key,构建这一映射关系
                match1[m] = t[i]
            else: # 哈希表里面已经建立了这一映射关系
                if match1[m] != t[i]: # 检验映射是否正确
                    return False
        match2 = {} # 注意反向映射一定也要来一遍，否则可能不满足一一映射的条件
        for i,m in enumerate(t):
            if m not in match2: # 如果哈希表里面原来没有这个key,构建这一映射关系
                match2[m] = s[i]
            else: # 哈希表里面已经建立了这一映射关系
                if match2[m] != s[i]: # 检验映射是否正确
                    return False
        return True
```

- 时间复杂度：O(n)（n为字符串长度）
- 空间复杂度：O(n)

拓展解法：使用zip()函数去替代字典显示出映射关系，set()用来去重，

如果要满足一一映射的关系，则下面程序中的三个长度要严格相等。

```python
def isIsomorphic(self, s, t):
    return len(set(zip(s, t))) == len(set(s)) == len(set(t))
```

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 收获

- 我开始没有意识到还要验证 t→s 的反向映射关系，深刻理解了题目中的一一映射的含义；
- 学会了zip()函数的使用

# 二、LeetCode 383. 赎金信

## 题目

字符串ransomNote能否由字符串magazine里面的字符构成（magazine中的每个字符只能在 ransomNote中使用一次），能则返回True。

## 解法：哈希表+计数

思路：我们先想不能构成的情况：

- 要么在ransomNote中存在的字符，在magazine里面不存在；
- 要么在ransomNote中存在的字符，虽然magazine里面也有，但是数量不如ransomNote里的多；

那么我们就既需要对字符进行查询操作，又要对同一种字符进行数量的比较操作，所以我们采用字典的结构解决这一问题。

代码：

```python
"""
题目问字符串ransomNote能否由字符串magazine里面的字符构成（magazine中的每个字符只能在 ransomNote中使用一次），能则返回True。
那不能构成的情况就是：
 要么在ransomNote中存在的字符，在magazine里面不存在；
 要么在ransomNote中存在的字符，虽然magazine里面也有，但是数量不如ransomNote里的多；
那么我们就既需要对字符进行查询操作，又要对同一种字符进行数量的比较操作，所以我们采用字典的结构解决这一问题。

时间复杂度：O(n)（n为ransomNote 和 magazine长度的较大值）
空间复杂度：O(n)（n为magazine长度）
"""

class Solution(object):
    def canConstruct(self, ransomNote, magazine):
        # 这里其实可以先进行一个前置的判断：如果ransomNote的长度大于magazine的长度，则必返回False（提前收工）
        if len(ransomNote) > len(magazine):
            return False
        stock = {} # 以字符为key，以对应的数量为value
        for c in magazine:
            stock[c] = stock.get(c, 0) + 1
            # 注意这里的get函数的参数含义：如果本次操作前c在字典中已经存在，则返回对应的value值，不存在则返回0.
        for i in ransomNote:
            if i not in stock: # 在ransomNote中存在的字符，在magazine里面不存在
                return False
            if stock[i] == 0: # 先判断stock里面是否还有i字符，没有的话就返回False
                return False
            stock[i] -= 1 # 用了一个就库存就减1
        return True
```

- 时间复杂度：O(n)（n为ransomNote 和 magazine长度的较大值）
- 空间复杂度：O(n)（n为magazine长度）

## 收获

- 这里我加了一个前置的提前收工的条件：如果ransomNote的长度都大于magazine的长度了，那它必然不能由magazine里面的字符构成；
- get()函数：比如stock.get(c,0)如果c(key)已存在，则返回对应value值；不存在则返回0；

# 三、Python 学习（五）

## zip()函数

zip 直译是"拉链"：把两个（或多个）可迭代对象像拉链两侧的齿一样按位置一一咬合，产出"配对"（元组）。

```python
list(zip('abc', [1, 2, 3]))
# [('a', 1), ('b', 2), ('c', 3)]  —— 每一对都是一个元组
```

**三个要点：**

1. **zip() 返回的是迭代器（惰性对象）**：直接 print 只能看到 `<zip object at ...>`，要包一层 `list()` 才能看内容——和 range 是同一类设计
2. **按最短的截断，且不报错**：`list(zip('abc', '12'))` 只有 `[('a','1'), ('b','2')]`，'c' 被悄悄丢掉。拉链有一边齿不够长，咬到短的那头就停。205 题保证 s 和 t 等长，所以随便 zip；想不截断要用 `itertools.zip_longest`（第 5 周内容）
3. **和 enumerate 是同一家族**：`enumerate(s)` 本质就是 `zip(range(len(s)), s)`——把"索引序列"和"元素序列"咬合。205 里用 enumerate 取 `(i, m)`，用 zip 就是取 `(c_s, c_t)` 配对，同一套思想

**三个常用姿势：**

```python
# 1. 配对遍历（比手动 range(len) 优雅）
for c1, c2 in zip('badc', 'baba'):
    print(c1, c2)

# 2. 一行解包还原（* 把列表摊开成多个参数）
pairs = [('a', 1), ('b', 2)]
s, t = zip(*pairs)   # s = ('a','b'), t = (1,2)  —— 注意还原出来的是元组

# 3. 秒建字典（dict 要吃成对数据，zip 现成供给）
dict(zip('abc', [1, 2, 3]))  # {'a': 1, 'b': 2, 'c': 3}
```

**在 205 里的角色**：`zip(s, t)` 把两个字符串咬合成"字符对序列"，`set` 吃掉它去重，再和两边各自的去重数比较——配对逻辑不用自己写循环，zip 代劳。
